# Project Name — The Blob

## Decision

The project name is **The Blob**. The canonical repository slug is `theblob`.

## Cultural lineage

The name is a deliberate homage to the 1958 science-fiction film *The Blob*, directed by Irvin S. Yeaworth Jr. The choice follows the playful Bell Labs tradition behind **Plan 9**, whose name references *Plan 9 from Outer Space* rather than a literal product version.

The intent is cultural lineage, not numerical succession: this project is not “Plan 10”. It treats Plan 9, Inferno, Plan B, Omero and Octopus as research ancestors worth studying and extending.

## Architectural metaphor

The metaphor fits the system unusually well:

- one entity can span many devices;
- it has no single fixed physical form;
- it can grow by incorporating new resources;
- it acquires capabilities as needed;
- its visible Surface changes with context and device;
- its persistent identity and history remain unified.

In project vocabulary, the Blob is not a binary blob or storage object. It is the complete personal adaptive computing environment.

## Naming conventions

- Product / project: **The Blob**
- Repository: `theblob`
- Avoid product names such as `BlobOS`, `Blob Linux`, or `AI Blob` unless a future subproject requires them.
- Internal component names should remain descriptive (`personal-world`, `workspace`, `capability`, `fabric`, `alfred`, etc.) until better domain names emerge.
