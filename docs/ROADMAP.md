# Research Roadmap

## Phase 0 — Vocabulary, archaeology and contracts

- Maintain `ARCHAEOLOGY.md` as the research lineage.
- Freeze only enough concepts to build MVP-0.
- Establish typed boundaries between AI semantics and deterministic authorization/resolution.
- Treat names and implementation technologies as revisable ADRs.

## Phase 1 — Single-node vertical slice

Personal World + Development Workspace + Alfred + one-role Requirement Graph + deterministic resolver + explainable Binding Plan/short Binding Lease + one ephemeral Capability backend + Temporal/Causal history + Slint Surface.

## Phase 2 — Capability runtime

- richer typed contracts and effect declarations;
- registry metadata;
- sandbox policy;
- caching/eviction;
- at least WASM plus OCI backends;
- adapter/converter edges;
- joint multi-role Requirement Graph resolution and converter-path solving.

## Phase 3 — Workspace system

Ready / AI Designed / Expert builders, Recipe versioning/forking, UI components, experience grammar, benchmark/optimization profiles, initial Workspace Registry format.

## Phase 4 — Second node / Compute Fabric

Add one remote Linux node and prove Fabric discovery, trust metadata, placement, late binding/re-resolution and shared Task state.

## Phase 5 — Knowledge Objects

Content-addressed storage, typed Projections, reactive derived Representations, semantic metadata, Views, provenance/confidence, object history and compatibility/introspection projections.

## Phase 6 — Alfred Situations

Move from simple deterministic correlation to multi-source temporal Situations with AI-assisted semantic interpretation, persistent context, policy and structured autonomous plans.

## Phase 7 — Adaptive system

Declarative SystemSpec, Nix backend, safe experiment branches, simulation/VM testing, benchmark/regression, causal recording and rollback.

## Phase 8 — Mobile Surface

Android/GKI node + shared Personal World + phone Surface for one existing Workspace/Task. Later add watch-level status/action Surface.

## Phase 9 — Capability synthesis research

Experiment with AI-generated adapters/capabilities behind strict typed contracts, sandboxing, automated tests, policy checks and local trust scopes.

## Phase 10 — Custom graphical substrate

Evaluate replacing Hyprland with a Smithay compositor once Surface/Workspace primitives are proven and the benefit is measurable.
